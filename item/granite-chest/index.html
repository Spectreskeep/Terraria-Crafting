Granite Chest in Terraria

Terraria item ID 3125. Terraria 1.4.5.7.

The Granite Chest is a chest storage item found only in Underground Cabins within Granite Caves. Like Marble Chests and Rich Mahogany Chests, Granite Chests have exactly the same loot as Gold Chests.

How to craft Granite Chest

Crafted at Work Bench. Ingredients:

  • Smooth Granite Block x8
  • Any Iron Bar x2

What Granite Chest is used to craft

  • Trapped Granite Chest
